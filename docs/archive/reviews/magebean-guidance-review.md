# Magebean guidance review

Scope: every Magebean catalog requirement. Guidance version 2 preserves the requirement-specific corrective action and verification. No criterion, check, profile membership or standards clause is changed.

Findings must identify actual observations. Collection instructions explain scanner access; they do not establish a deployment vulnerability. An absent optional app/code directory produces no finding. Findings remain independent.
